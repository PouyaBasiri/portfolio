# Pouya Basiri — Portfolio

React 19 + Vite + TypeScript + Tailwind CSS v4 + Framer Motion.
Design language follows the SurinRayan project (slate-950 base, corporate blue, glass cards, shimmer).

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173
```

## Customize

All content lives in **`src/data.ts`**. Search for `TODO` and replace the placeholders
(email, LinkedIn, experience, stats, extra projects, achievements).

## Build

```bash
npm run build      # outputs to dist/
npm run preview    # serve the production build locally
```
